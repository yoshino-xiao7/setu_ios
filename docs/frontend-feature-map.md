# 前端功能到 iOS 模块映射

本文件以 `setu_cloud/src/router/index.ts` 和 `setu_cloud/src/api/` 为来源，记录 iOS 原生开发的功能覆盖顺序。前端只作为功能和接口参考，iOS 不复制 Web 视图，也不做 WebView 套壳。

## 第一批：App Shell 与首页数据

- 仪表盘：`/usage/overview`、`/points/me`、`/status/overview`、`/notifications/unread-count`。已接入 iOS 首页。
- 账号：`/auth/login`、`/auth/register`、`/auth/forgot-password`、`/auth/reset-password`、`/auth/refresh-signature`、`/auth/logout`、`/user/info`
- 移动端能力：`/mobile/capabilities`、APNs 设备绑定、Live Activity token

## 已开始原生实现

- 认证：登录、注册、找回密码、重置密码、刷新签名密钥、退出登录。
- 个人中心：资料读取、昵称修改、头像上传。
- QQ 绑定：读取绑定状态、发送验证码、保存绑定、停用绑定。
- 安全设置：修改密码并清理本地会话。
- 通行密钥：已绑定 Passkey 列表、重命名、删除、原生注册、原生登录；真机使用需绑定 Associated Domains 和线上 WebAuthn RP ID。
- 开发文档 / 关于 / 隐私政策：原生静态阅读页第一版。
- API Keys：列表、创建、启停、删除。
- 积分调用：余额、参数表单、/setu/v2 调用、结果展示、收藏、删除申请、打开原图。
- 积分流水：分页列表第一版。
- 我的收藏夹：收藏夹列表、创建、编辑、删除、详情、图片条目、分享/取消分享、移除图片、设置封面。
- 默认收藏：默认收藏列表、取消收藏。
- 收藏夹广场：公开收藏夹列表、排序、点赞、收藏、公开用户主页。
- 图库投稿：批次初始化、PhotosPicker 选图、草稿恢复、直传、状态回写、完成提交、我的投稿批次列表、状态筛选、批次详情、取消批次第一版。
- AI 绘图历史：分页列表、状态筛选、任务详情、临时图片链接、下载链接、公开审核、删除申请。
- AI 绘图：服务状态、能力列表、提示词翻译、创建生成任务第一版。
- AI 资产选择：LoRA、角色、风格预设浏览、搜索、分类筛选、详情查看、写入 AI 绘图草稿第一版。
- AI 广场：公开作品列表、分类筛选。
- 音乐：搜索、热门搜索、播放地址、歌词、MV 详情与播放地址、AVPlayer 后台播放、锁屏 Now Playing/远程播放暂停、记录播放、搜索结果加入歌单、我的歌单列表、歌单详情、新建/删除歌单、播放模式、移除歌曲、播放历史列表与清空。
- 通知中心：列表、未读筛选、标记已读、全部已读。
- 系统状态：状态概览和健康检查展示。
- 我的删除申请：分页列表、申请详情、状态、图片信息、审核信息。
- 管理后台：后台概览统计、图库统计同步、管理模块入口第一版、用户管理列表/详情/封禁/解封/积分发放、IP 黑名单和临时封禁管理、网易云 Token 管理、图片删除申请审核、图片库管理、投稿审核、Pixiv 爬虫、AI 生成记录、AI Worker 状态、AI 审核队列、AI 删除申请、操作日志。

## 用户端功能

- API Keys：列表、创建、启停、重命名、删除。
- 个人中心：资料、昵称、头像、密码、通行密钥。
- QQ 绑定：验证码、保存、禁用。
- 开发文档：原生文档视图或静态内容。
- 系统状态：公开状态与用户内嵌状态。
- 积分调用：余额、调用、流水。
- 收藏夹：我的收藏夹、收藏夹详情、公开分享。
- 收藏夹广场：列表、点赞、收藏、公开用户主页。
- 图库投稿：批次初始化、直传、状态回写、恢复、取消。
- AI 绘图：创建任务、提示词翻译、状态、历史、公开审核、删除申请、资产选择。
- AI 广场：公开作品列表。
- 音乐：搜索、播放 URL、歌词、歌单、播放历史、后台播放第一版。
- 通知中心：列表、未读数、标记已读。
- 我的删除申请：图片删除申请列表与详情。

## 管理端功能

- 后台概览：统计和管理入口第一版。
- 用户管理：列表、搜索、分页、详情、封禁/解封、积分发放、用户 API Keys 展示第一版。
- 黑名单：固定 IP 黑名单列表、搜索、添加/批量添加、移除、临时封禁列表、解除/清空。
- 系统监控。
- 网易云 Token 管理：列表、添加、编辑、启停、删除、Cookie 脱敏展示、VIP 歌曲可播性检测。
- 图片删除申请：管理员列表、待审核队列、状态筛选、详情、批准/拒绝审核第一版。
- Pixiv 爬虫：健康检查、按作品 ID/画师/标签创建任务、任务列表、任务详情、日志查看、取消任务第一版。
- 图片库管理：正式图库列表、未审核/复审/全部筛选、PID/p/可用性筛选、可用性检测、单张/批量审核、删除申请第一版。
- 投稿审核：管理员投稿批次列表、状态筛选、详情、批准/拒绝审核、立即发布、审核备注、标签/R18/AI 类型调整第一版。
- AI 生成记录：任务/用户/状态筛选、图片预览、提示词和排错链路、下架、删除、删除本机图片指令第一版。
- AI Worker 状态：服务在线状态、队列分布、Worker 节点、模型能力、启动/停止/重启控制第一版。
- AI 审核队列：审核列表、状态/分类筛选、图片预览、通过/拒绝审核第一版。
- AI 删除申请：列表、状态筛选、图片预览、批准/拒绝审核第一版。
- 操作日志：列表、Trace/用户/事件/状态/code/目标筛选、分页、详情和请求/响应 payload 展示第一版。

## 开发规则

1. 每个模块先补 Core client 和 DTO，再做 SwiftUI 页面。
2. 所有受保护请求沿用 `SID` Cookie + `signSecret` HMAC。
3. 上传、音乐、Live Activities 先按移动端契约实现，再做高级体验。
4. 管理端默认只对 `role == admin` 用户显示入口。
