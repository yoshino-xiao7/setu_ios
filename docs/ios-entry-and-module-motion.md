# 亦可开屏与模块过渡

实现位置：`RootAppView`、`BrandSplashView`、`HomeWelcomeAnimation`、`ModuleTabTransition`。

- 未登录冷启动：光绘 YK Logo，随后移到欢迎页 Logo 的实际布局锚点；约 2 秒。
- 已登录冷启动：光绘 Logo → 双角色与时段问候 → 问候缩小并移动到首页原有标题锚点；约 3.65 秒。
- 新登录：保留登录页显示成功确认 280 ms → 淡出 330 ms → 双角色、问候描绘及收束 2.29 秒。社交登录显示成功提示。
- 问候直接使用首页标题与测量尺寸，昵称、时段、Dynamic Type 和换行遵循首页。描绘是字体轮廓，不是汉字真实笔顺；彩色字形不支持轮廓时由最终原生文字显示。
- 角色使用已确认的透明图片和轻量连续网格动作，不是新制作的骨骼动画。
- 五个底栏模块按排列方向平移淡入，340 ms。保留原生 TabView 和各模块 NavigationStack，播放器仍由原来的共享浮层承载；详情仍使用原生导航推进/返回。
- 减少动态效果时禁用角色、文字移动与模块平移，使用短淡入。前后台恢复不重新播放开屏。
- 推送目的地在开屏结束后处理，避免目的地抢先覆盖欢迎动画。

验证：使用 UI fixture 检查密码登录、已登录冷启动、前后台恢复、模块往返、导航栈与播放器实例保留、减少动态效果。375 点模拟器另有原生开屏录屏和逐帧截图。未进行真实账号 Apple/通行密钥授权或真机安装验收。
