# 音乐功能真机验证清单

更新时间：2026-07-08

以下项目依赖真实设备、锁屏或后台音频环境，自动化测试与 generic iOS build 只能证明编译和纯逻辑路径。

## P0 封面与锁屏

- 播放包含 `http://p*.music.126.net` 封面的歌曲，列表、播放页、mini bar 均显示封面。
- 断网后进入封面失败态，恢复网络后点击封面可重试加载。
- 锁屏/控制中心展示歌曲标题、歌手、专辑与封面。

## P1 播放页与歌词

- 全屏播放页在 iPhone SE 宽度与 Pro Max 宽度无重叠、截断或控件溢出。
- 播放/暂停时封面动效正常；开启“减少动态效果”后动效降级。
- LRC 歌词随进度高亮并居中滚动，点击歌词可跳转播放进度。
- 开启歌词常亮后屏幕不自动熄灭，退出播放页后恢复系统默认熄屏行为。

## P2 播放健壮性

- 高音质不可用时自动降级到标准音质，并显示「已切换标准音质」。
- 自动连播切到下一首后，播放历史新增对应歌曲。
- 睡眠定时 15/30/60 分钟到点后渐弱暂停。
- 睡眠定时「播完本曲」在当前歌曲结束时暂停，不继续自动连播。
- 队列管理支持拖拽排序、滑动移除、清空待播与「下一首播放」。

## P3 首页、搜索、批量

- 音乐首页首屏顺序为搜索入口、最近播放、我的歌单、热门搜索。
- 搜索结果可在歌曲/歌手/专辑间切换，歌曲分页加载更多仍可用。
- 搜索历史胶囊可单条删除，也可清空。
- 歌单详情多选模式显示选中计数，支持批量移除与批量加入其它歌单。
