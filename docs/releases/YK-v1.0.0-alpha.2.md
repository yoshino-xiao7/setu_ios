# 亦可 YK iOS YK-v1.0.0-alpha.2

源码更正发布。

**请用这一版，不要再用 `YK-v1.0.0-alpha.1` 的源码包。** 上一版公开 README 里误放了私有后端和 Web 仓库的 GitHub 地址。本版本已删除这些链接，只说明客户端连接亦可自己的 API，不再指向内部项目。

其余内容与首次 Alpha 相同：**只提供源码**，没有 ipa / TestFlight。需要 **iOS 17+**。功能说明见仓库 README。

```bash
git clone https://github.com/yoshino-xiao7/setu_ios.git
git checkout YK-v1.0.0-alpha.2
```
